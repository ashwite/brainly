# Mudoku

Hier entsteht das Krimi-Rätsel für „Kleine Denkpause“. Ich ordne Verdächtige ihren Standorten zu und finde so heraus, wer zur Tatzeit am Tatort war.

| Pfad | Was hier später liegt |
|---|---|
| `index.html` | Die Startseite mit Fallakte, Verdächtigen und Raumplan |
| `scripts/` | Die Spiellogik für Zuordnung, Prüfung und Auflösung |
| `styles/` | Das Design des Rätselspiels |
| `data/` | Die Fälle mit Hinweisen und Lösungen |
